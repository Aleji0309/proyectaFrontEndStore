
# Front-End Store  

## Description  
This project is an **online store** created as part of a **Udemy course**. The goal was to practice and apply **web design**, **HTML**, and **CSS** techniques to build a functional store with an appealing design.

## What I Learned  
This project helped me improve my skills in **responsive design**, **layout structuring**, and **styling** using CSS. It also enhanced my ability to build attractive and functional web pages without relying on JavaScript.  

## Ongoing Development  
I plan to refine the design further and experiment with **advanced CSS techniques** and **accessibility improvements** to enhance the user experience.
