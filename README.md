A responsive and clean **e-commerce website** built using **HTML, CSS, and vanilla JavaScript**. FrontEnd Store simulates a basic online shop with a homepage, product listings, and a blog section — all fully static.

## 🛠️ Technologies Used

- **HTML5** – Semantic page structure  
- **CSS3** – Responsive grid layout, media queries, styling  
- **JavaScript (ES6+)** – Basic interactivity and dynamic elements  
- **Netlify** – Hosting and deployment

## 📋 Project Description

FrontEnd Store is a fictional online shop developed to practice static site architecture and layout design. The website includes:

- Homepage with hero section and call-to-action  
- Product gallery page  
- Blog or news section  
- Responsive navigation and footer

This project does **not include a shopping cart** or backend — it's focused on layout, styling, and presentation.

## 📌 Key Features

- Multi-page layout: Home, Store, Blog, Contact  
- Responsive design with Flexbox and media queries  
- Visual consistency across sections  
- Lightweight, fast-loading static pages  
- Styled buttons, image cards, and accessible text hierarchy

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Aleji0309/proyectaFrontEndStore.git
````

2. Navigate to the project folder:

```bash
cd proyectaFrontEndStore
```

3. Open any `.html` file (e.g. `index.html`) in your browser.

> No setup required — this is a static project.
